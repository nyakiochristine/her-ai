## 1\. Does ChatGPT actually remember you?

**Takeaway:** The language model itself remembers nothing. "Memory" is a feature built around it. **Tool:** ChatGPT (also works in Claude) · **Background:** dark green · **Length:** \~40s · **Voiceover:** \~88 words

**Off-camera setup**

- Settings → Personalization: switch off **both** "Reference saved memories" and "Reference chat history".
- Open a fresh chat and hide the sidebar.

| Time | Screen (computer use) | Voiceover | On-screen text |
| :---- | :---- | :---- | :---- |
| 0:00–0:03 | Empty chat | "Does ChatGPT actually remember you? Let's test it." | **Does ChatGPT remember you?** |
| 0:03–0:12 | Type: *For lunch today I had bread with avocado, an egg and some ketchup.* Send. The reply appears. | "Tell it what you had for lunch." … "It's very supportive." |  |
| 0:12–0:17 | Click **New chat**. Type: *What did I have for lunch today?* Send. | "Now open a new chat and ask." |  |
| 0:17–0:21 | The reply lands. Hold for 2s. | "No idea." |  |
| 0:21–0:33 | Stay on the reply. | "That's not a bug. The language model itself remembers nothing. Every chat starts blank. Memory is an extra feature built around the model. When it's on, it saves details about you and brings them into new chats." |  |
| 0:33–0:37 | Stay on the reply. | "Try it tonight: switch memory off, and ask the same question." |  |
| 0:37–0:40 | Fade to the background colour. | "There's more under the hood. her/ai workshops and webinars, link in bio." |  |

**Green highlight:** 0:17–0:21, under the sentence where it says it doesn't know what you had for lunch.

**If the output doesn't cooperate:**

- *It remembers the lunch:* memory is still on. Check both settings and record again.
- *It guesses a lunch:* even better. Highlight the guess and change the 0:17 line to "It… guesses."

**Instagram caption:**

Does ChatGPT actually remember you? 🥑

We told it our lunch. Opened a new chat. Asked again. Nothing.

The language model itself has no memory: every chat starts blank. "Memory" is a separate feature built around the model that saves details about you and pulls them into new chats. Handy, but worth knowing what it's keeping and where.

Try it yourself:

1\. Settings → Personalization → switch off memory and chat history

2\. Tell it what you had for lunch

3\. Open a new chat and ask what you ate

## 2\. Can AI actually do math?

**Takeaway:** A language model predicts numbers. For real calculations, a tool around the model writes code to do the math. **Tool:** ChatGPT, using a model or setting that visibly shows its "thinking / analyzing" step (test this first) · **Background:** orange · **Length:** \~40s · **Voiceover:** \~89 words

**Off-camera setup**

- Open a fresh chat and hide the sidebar.
- Do a test run to confirm that the hard sum triggers visible code.

| Time | Screen (computer use) | Voiceover | On-screen text |
| :---- | :---- | :---- | :---- |
| 0:00–0:03 | Empty chat | "Can AI actually do math?" | **Can AI actually do math?** |
| 0:03–0:08 | Type: *What is 10 \+ 10?* Send. "20" appears. | "Ten plus ten." … "Twenty. Instantly." |  |
| 0:08–0:13 | Type: *What is 48,213 × 7,946 − 1,287?* Send. | "Now something harder." |  |
| 0:13–0:22 | The model shows its thinking step, writes code and runs it. The answer appears. Cut the waiting time if needed. | "Watch. It stops, writes a little code, and runs it. It's building its own calculator." |  |
| 0:22–0:34 | Scroll back so the code block is visible. | "Because the language model doesn't calculate. It predicts. Twenty was simply the most likely next word. Like a toddler guessing you're two hundred: right size of number, not the real one. For hard sums, a tool does the actual math." |  |
| 0:34–0:37 | Stay on the code block. | "For numbers that matter, like your taxes, tell it: calculate this with code." |  |
| 0:37–0:40 | Fade to the background colour. | "her/ai workshops and webinars. Link in bio." |  |

**Green highlight:** 0:13–0:22, around the code block, or the "analyzing" label if that is what is visible.

**If the output doesn't cooperate:**

- *It answers the hard sum without code:* check the answer with a calculator. If it's wrong, that's a great reel: change the 0:13 line to "Confident. And wrong." If it's right, re-run with a thinking model, or start the prompt with "Calculate:".
- *It uses code even for 10 \+ 10:* say so honestly ("It even builds a calculator for this one"), and keep the reveal as it is.

**Instagram caption:**

Can AI actually do math? 🧮

Ten plus ten: instant. A big sum: it stops, writes code, runs it.

That's because the language model doesn't calculate, it predicts the most likely next word. For an easy sum that works. For a hard one, a tool built around the model does the real math.

Try it yourself:

1\. Ask "What is 10 \+ 10?"

2\. Ask a big sum, and watch whether it writes code

3\. For anything that matters (taxes, invoices): say "calculate this with code"

## 3\. Ask AI for a CEO. Guess who shows up.

**Takeaway:** AI isn't neutral. It mirrors its training data, and the data mirrors us. **Tool:** Midjourney (the same prompts work in any image generator) · **Background:** light green · **Length:** \~40s · **Voiceover:** \~88 words

**Off-camera setup**

- Log in to Midjourney and open the create screen.
- **Use the first grid for each prompt. Don't re-roll** (see the recording rules).

| Time | Screen (computer use) | Voiceover | On-screen text |
| :---- | :---- | :---- | :---- |
| 0:00–0:03 | Empty prompt bar | "Ask an image AI for a CEO. Guess who shows up." | **Ask AI for a CEO.** |
| 0:03–0:08 | Type: *a photo of a CEO in a meeting room*. Submit. Cut the generation wait. |  |  |
| 0:08–0:14 | The grid of four images appears. Hold. | "Men in suits. Nearly every time." |  |
| 0:14–0:20 | Type: *a photo of Queen Elizabeth in a yellow raincoat*. Submit. Cut the wait. | "Now Queen Elizabeth in a yellow raincoat." |  |
| 0:20–0:24 | The grid appears. Hold. | "Almost always the older Queen." |  |
| 0:24–0:34 | Show both grids side by side, or scroll between them. | "The model learned from photos online. There are more pictures of male CEOs, and far more of the Queen in later life. AI isn't neutral. It mirrors its data, and the data mirrors us." |  |
| 0:34–0:38 | Stay on the grids. | "Try it: ask for a nurse, a pilot, a scientist. What do you see?" |  |
| 0:38–0:40 | Fade to the background colour. | "Spotting bias is a skill. her/ai workshops and webinars, link in bio." |  |

**Green highlight:** 0:08–0:14, around the CEO grid.

**If the output doesn't cooperate:**

- *The grid includes a woman or more variety:* keep it and narrate what you see, for example "Mostly men. One woman, out of four." Never re-roll to make the result look worse.
- *A younger Queen appears:* say so ("Mostly the older Queen. This time, one younger one."). The point still holds.

**Instagram caption:**

Ask AI for a CEO. Guess who shows up. 👔

Men in suits. And Queen Elizabeth? Almost always in her later years.

Image models learn from photos online. There are more pictures of male CEOs, and far more of the Queen when she was older, so that's what the model predicts. Technology isn't neutral: it reflects the data, and the data reflects us.

Try it yourself:

1\. Open any image generator

2\. Ask for "a CEO", "a nurse", "a pilot", "a scientist"

3\. Look at who it shows you, and who it doesn't

## 4\. Does AI know what happened last week?

**Takeaway:** A model's knowledge stops at its training cutoff. Anything newer only comes in through a search tool. **Tool:** Claude or ChatGPT. Do a test run to check whether the tool searches the web on its own; Claude's web search toggle is the easiest to control. · **Background:** dark green · **Length:** \~40s · **Voiceover:** \~90 words

**Off-camera setup**

- Switch web search **off**.
- Choose a recent event from the last 1–2 weeks that is clearly after the model's cutoff. Pick something neutral: a sports final, a product launch, an award. Nothing political or tragic.
- Open a fresh chat and hide the sidebar.

| Time | Screen (computer use) | Voiceover | On-screen text |
| :---- | :---- | :---- | :---- |
| 0:00–0:03 | Empty chat | "Does AI know what happened last week?" | **Does AI know what happened last week?** |
| 0:03–0:11 | Type: *When were you last trained?* Send. The answer shows a date. | "Ask it when it was last trained." … "There's a date. Its knowledge stops there." |  |
| 0:11–0:20 | Type: *Who won \[recent event\]?* Send. It doesn't know, or answers with outdated information. | "Now ask about something from last week." … "It doesn't know. Or worse, it guesses." |  |
| 0:20–0:27 | Switch web search **on**. Ask the same question again. The answer appears with sources. | "Switch on web search." … "Now it looks it up." |  |
| 0:27–0:33 | Stay on the answer with its sources. | "A model is baked once, like bread. After that, anything new only comes in through a search tool." |  |
| 0:33–0:37 | Stay on the sources. | "So for anything recent: tell it to search, and check the sources." |  |
| 0:37–0:40 | Fade to the background colour. | "her/ai workshops and webinars. Link in bio." |  |

**Green highlight:** 0:03–0:11, under the cutoff date in its first answer.

**If the output doesn't cooperate:**

- *It searches automatically in step 2:* keep it, and change the line to "It went searching. That's a tool, not its own knowledge." Skip the 0:20 step and stretch the reveal.
- *It knows the event without searching:* the event happened before the cutoff. Pick a newer one.

**Instagram caption:**

Does AI know what happened last week? 📅

Ask it when it was last trained, and you'll get a date. That's where its knowledge stops.

A model is trained once, then used for months. Anything newer it can only find through a web search tool, and without one it may simply guess. (Also a good reason not to ask a chatbot who to vote for.)

Try it yourself:

1\. Ask "When were you last trained?"

2\. Ask about something from last week, with web search off

3\. Turn search on, ask again, and check the sources
